# AI 绘本朗读 App V1 开发任务单

本文档用于把 `docs/implementation-plan.md` 继续落成可执行任务。

使用方式：

1. 按优先级顺序推进
2. 每个任务完成后勾选
3. 如有范围变更，先同步 `docs/v1-breakdown.md` 和 `docs/implementation-plan.md`

## 1. 当前目标

当前目标是完成 MVP 闭环：

1. 创建绘本
2. 导入多页图片
3. 编辑页面文本
4. 生成页面文本
5. 生成页面语音
6. 单页播放
7. 整本连续播放
8. 本地保存数据与文件

## 2. 任务分组

任务按以下阶段推进：

1. T0 页面骨架
2. T1 类型与数据层
3. T2 绘本创建与图片导入
4. T3 文本生成
5. T4 语音生成与播放
6. T5 设置页与配置管理
7. T6 稳定性与收尾

## 5. T2 绘本创建与图片导入

目标：打通“创建绘本 + 导入图片 + 保存页面”的本地主流程。

前置依赖：

1. T0 完成
2. T1 完成

### T2-1 新建绘本表单

- [ ] 实现绘本名称输入
- [ ] 实现语言选择，仅支持 `中文 / 英文`
- [ ] 增加保存按钮
- [ ] 增加基本表单校验

验收标准：

1. 名称为空时不可保存
2. 语言必须明确选择或给出默认值

### T2-2 图片选择与导入

- [ ] 接入相册多选能力
- [ ] 保留选择顺序
- [ ] 导入后复制到本地私有目录
- [ ] 为每张图片创建页面记录

验收标准：

1. 一次可以导入多张图片
2. 每张图对应一条页面记录
3. 图片文件路径持久化保存

### T2-3 页面排序

- [ ] 在新建绘本页支持调整页面顺序
- [ ] 保存时写回 `pageIndex`
- [ ] 详情页按 `pageIndex` 展示

验收标准：

1. 调整顺序后再次进入仍保持正确顺序

### T2-4 绘本列表与详情真实数据

- [ ] 首页读取绘本列表
- [ ] 绘本卡片显示封面、名称、语言、页数
- [ ] 绘本详情页显示页面缩略图列表
- [ ] 支持删除绘本

验收标准：

1. 新建完成后首页可见绘本
2. 删除绘本后列表同步更新

## 6. T3 文本生成

目标：打通 Vision 配置和页面文本生成。

前置依赖：

1. T1 完成
2. T2 完成

### T3-1 Provider 抽象

- [ ] 新增 `lib/providers/openai-compatible.ts`
- [ ] 新增 `lib/providers/vision.ts`
- [ ] 定义统一的内容生成接口
- [ ] 统一错误结构

验收标准：

1. 页面层不直接发网络请求
2. 可以根据配置调用 OpenAI 兼容接口

### T3-2 单页生成文本

- [ ] 页面详情页增加“生成文本”按钮
- [ ] 读取页面图片并调用 Vision Provider
- [ ] 写回 `originalText`
- [ ] 写回 `sceneDescription`
- [ ] 写回 `readAloudText`
- [ ] 更新 `textStatus`

验收标准：

1. 单页可独立生成三段文本
2. 失败时可看到错误状态

### T3-3 文本编辑与手动修改标记

- [ ] 页面详情页支持编辑三段文本
- [ ] 保存编辑结果
- [ ] 设置 `hasManualEdit`
- [ ] 编辑后标记“待更新语音”

验收标准：

1. 手动修改后刷新页面仍保留结果
2. 后续生成语音使用最新 `readAloudText`

### T3-4 整本逐页生成文本

- [ ] 绘本详情页增加“生成整本内容”按钮
- [ ] 按页顺序逐页生成
- [ ] 单页失败不阻塞后续页面
- [ ] 展示进行中状态

验收标准：

1. 可以一键触发整本生成
2. 个别失败页不影响其他页完成

### T3-5 文本覆盖确认

- [ ] 若 `hasManualEdit` 为真，再生成前弹确认
- [ ] 确认后覆盖旧文本
- [ ] 取消后保持现状

验收标准：

1. 手动编辑内容不会被静默覆盖

## 7. T4 语音生成与播放

目标：打通 TTS 生成、音频保存、单页播放和连续播放。

前置依赖：

1. T3 基本完成

### T4-1 TTS Provider 抽象

- [ ] 新增 `lib/providers/tts.ts`
- [ ] 定义统一语音生成接口
- [ ] 返回音频二进制或可保存结果
- [ ] 统一错误结构

验收标准：

1. TTS 调用和 Vision 调用职责分离

### T4-2 单页生成语音

- [ ] 页面详情页增加“生成语音”按钮
- [ ] 校验 `readAloudText` 非空
- [ ] 调用 TTS Provider
- [ ] 写入本地音频文件
- [ ] 保存 `audioPath`、`audioDuration`
- [ ] 更新 `audioStatus`

验收标准：

1. 单页可生成本地音频
2. 再次生成时覆盖旧音频

### T4-3 单页播放

- [ ] 新增 `lib/playback/player.ts`
- [ ] 页面详情页增加播放 / 暂停
- [ ] 展示基础进度信息
- [ ] 支持倍速播放

验收标准：

1. 已生成语音页可直接试听
2. 播放状态和 UI 基本同步

### T4-4 整本逐页生成语音

- [ ] 绘本详情页增加“生成整本语音”按钮
- [ ] 跳过 `readAloudText` 为空的页面并记录失败
- [ ] 逐页生成并保存状态

验收标准：

1. 可以一键生成整本语音
2. 某页失败不影响其他页

### T4-5 连续播放

- [ ] 绘本详情页增加“连续播放”入口
- [ ] 按 `pageIndex` 顺序播放
- [ ] 播放结束自动切换下一页
- [ ] 回写 `currentPageIndex`
- [ ] 遇到无音频页时停止并提示

验收标准：

1. 已有音频的页面可连续播放
2. 最近播放页会被记录

目标：让生成相关配置可录入、可编辑、可选择默认值。

1. T1 完成

### T5-1 配置列表与表单

验收标准：

### T5-3 默认配置设置

验收标准：

## 9. T6 稳定性与收尾

目标：补齐规则、清理逻辑和发布前基础检查。

### T6-1 页面状态与错误提示

- [ ] 明确展示 `textStatus`
- [ ] 明确展示 `audioStatus`
- [ ] 展示失败原因 `lastError`
- [ ] 支持失败后重试

验收标准：

1. 用户能看出当前页卡在哪一步

### T6-2 删除与清理

- [ ] 删除绘本时删除图片目录
- [ ] 删除绘本时删除音频目录
- [ ] 增加缓存清理入口

验收标准：

1. 删除后不会留下明显孤儿文件

### T6-3 边界规则补齐

- [ ] 空 `readAloudText` 禁止生成语音
- [ ] 手动编辑后重新生成文本需要确认
- [ ] 重新生成语音直接覆盖旧文件
- [ ] 连续播放遇无音频页停止并提示

验收标准：

1. 行为与 `docs/v1.md` 描述一致

### T6-4 验证与整理

- [ ] 运行 `pnpm lint`
- [ ] 手动验证首页、新建页、详情页、页面详情页、设置页
- [ ] 手动验证新建、导入、生成、播放、删除主链路
- [ ] 清理调试日志
- [ ] 更新 README 或相关文档

验收标准：

1. 代码可通过 lint
2. 主链路可重复操作

## 10. 建议开发顺序

建议严格按以下顺序推进：

1. T0 页面骨架
2. T1 类型与数据层
3. T5 设置页基础版
4. T2 绘本创建与图片导入
5. T3 文本生成
6. T4 语音生成与播放
7. T6 稳定性与收尾

说明：

1. T5 虽然排在后面，但配置能力最好在接文本生成前先做出基础版
2. 不建议先写播放器或模型调用细节，再回头补主流程

以下内容明确不进入当前开发批次：

1. 拍照导入
2. 图片裁剪
3. 图片旋转
4. 绘本级模型覆盖
5. 多配置模板管理优化

8. PDF 导入
