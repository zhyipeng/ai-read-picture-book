# AI 绘本朗读 App V1 需求拆分

本文档基于 `docs/v1.md`，将原始需求整理为更适合开发执行的拆分版本。

配套实施文档：

1. `docs/implementation-plan.md`

## 1. 拆分目标

将 V1 需求拆成三层：

1. 产品模块拆分：明确需要做哪些功能模块
2. 开发阶段拆分：明确先做什么、后做什么
3. 开发任务拆分：明确可以直接进入实现的任务项

## 2. V1 核心目标

V1 需要优先跑通以下闭环：

1. 创建绘本
2. 导入多页图片
3. 生成页面文本
4. 编辑页面文本
5. 生成页面语音
6. 单页播放与整本连续播放
7. 本地持久化保存图片、文本、音频

不在 V1 范围内的内容：

1. 多用户
2. 登录注册
3. 服务端
4. 云同步
5. 公共分享
6. PDF 导入
7. 跨页识别
8. 自动后台处理
9. 成本统计与 token 统计
10. 音频/文本导出

## 3. 产品模块拆分

### 3.1 绘本管理

目标：支持本地创建、查看、编辑、删除绘本。

功能点：

1. 绘本列表展示
2. 新建绘本
3. 编辑绘本名称
4. 删除绘本
5. 查看绘本详情
6. 展示封面、语言、页数、生成进度
7. 记录最近播放页

建议状态字段：

1. 未开始
2. 部分已生成
3. 全部文本已生成
4. 全部语音已生成

### 3.2 页面管理

目标：支持一本绘本下的多页管理。

功能点：

1. 导入页面图片
2. 页面缩略图预览
3. 页面大图查看
4. 拖拽排序
5. 删除页面
6. 查看页面处理状态

页面状态建议：

1. 未生成文本
2. 文本已生成
3. 语音已生成
4. 生成失败
5. 已编辑待更新语音

后置功能：

1. 替换页面图片
2. 设置封面页

### 3.3 图片导入

目标：完成本地图片导入与文件落地。

功能点：

1. 相册多选导入
2. 按选择顺序生成页面
3. 删除误上传图片
4. 导入后复制到 App 私有目录

后置功能：

1. 拍照导入
2. 图片旋转
3. 图片裁剪

### 3.4 页面内容生成

目标：根据单页图片生成可编辑的文本内容。

每页输出字段：

1. `originalText`
2. `sceneDescription`
3. `readAloudText`

功能点：

1. 单页生成文本
2. 整本逐页生成文本
3. 单页失败不影响其他页
4. 失败后支持重试
5. 三段文本可手动编辑

覆盖规则：

1. 未手动编辑时，允许直接覆盖生成结果
2. 已手动编辑时，再次生成前需要二次确认

### 3.5 语音生成

目标：将页面朗读文本转成可本地播放的音频。

功能点：

1. 单页生成语音
2. 整本逐页生成语音
3. 重新生成并覆盖旧音频
4. 试听当前页音频

规则：

1. TTS 输入固定使用 `readAloudText`
2. `readAloudText` 为空时禁止生成
3. 音频重新生成不影响现有文本

需保存信息：

1. `audioPath`
2. `audioDuration`
3. `audioGeneratedAt`
4. `ttsModel`
5. `ttsVoice`

### 3.6 播放器

目标：支持单页播放和整本连续播放。

功能点：

1. 播放 / 暂停
2. 上一页 / 下一页
3. 连续播放
4. 播放进度展示
5. 倍速播放
6. 当前页高亮
7. 记住最近播放页

V1 建议规则：

1. 连续播放仅播放已有音频的页面
2. 遇到无音频页面时停止并提示

后置功能：

1. 单页循环
2. 页间停顿设置

### 3.7 模型配置与设置

目标：支持用户配置生成服务，并按语言选择默认配置。

功能点：

1. 多模态模型配置管理
2. TTS 配置管理
3. 中文默认 Vision 配置
4. 英文默认 Vision 配置
5. 中文默认 TTS 配置
6. 英文默认 TTS 配置
7. 默认播放倍速设置
8. 本地缓存管理
9. 隐私与免责声明

后置功能：

1. 多配置模板管理优化
2. 绘本级模型覆盖
3. 高级参数配置

### 3.8 本地存储与安全

目标：保证纯本地使用、数据可恢复、敏感信息不泄露。

功能点：

1. 本地数据库保存结构化数据
2. 本地文件系统保存图片与音频
3. 删除绘本时清理关联文件
4. API Key 使用安全存储
5. 日志中禁止明文输出 Key
6. App 重启后保留状态与数据

## 4. 页面拆分

### 4.1 绘本列表页

职责：

1. 展示全部绘本
2. 提供新建绘本入口
3. 展示封面、名称、语言、页数、进度
4. 进入绘本详情页
5. 删除绘本

### 4.2 新建绘本页

职责：

1. 输入绘本名称
2. 选择绘本语言
3. 选择并导入多张图片
4. 调整页面顺序
5. 保存绘本

### 4.3 绘本详情页

职责：

1. 展示页面缩略图列表
2. 展示每页状态
3. 触发整本生成文本
4. 触发整本生成语音
5. 触发连续播放
6. 进入单页详情

### 4.4 页面详情页

职责：

1. 展示页面大图
2. 编辑 `originalText`
3. 编辑 `sceneDescription`
4. 编辑 `readAloudText`
5. 生成文本
6. 生成语音
7. 播放试听

### 4.5 设置页

职责：

1. 管理 Vision 配置
2. 管理 TTS 配置
3. 设置中英文默认模型
4. 设置默认播放参数
5. 管理本地缓存

## 5. 技术模块拆分

### 5.1 数据层

建议表结构：

1. `books`
2. `pages`
3. `model_configs`
4. `app_settings`

核心任务：

1. 数据库初始化
2. 表结构设计
3. 基础 CRUD
4. 排序字段维护
5. 状态字段维护

### 5.2 文件存储层

核心任务：

1. 图片导入后复制到私有目录
2. 语音生成后保存到私有目录
3. 删除绘本时清理图片和音频文件
4. 统一文件命名规则

建议目录结构：

1. `books/{bookId}/pages/{pageId}.jpg`
2. `books/{bookId}/audio/{pageId}.mp3`

### 5.3 模型调用层

建议抽象：

1. `VisionProvider`
2. `TTSProvider`

建议接口：

1. `generatePageContent(pageImage, language, config)`
2. `generateSpeech(text, config)`

核心任务：

1. 统一 OpenAI 兼容请求封装
2. 区分 Vision 与 TTS 配置
3. 统一错误处理和错误信息回传
4. 控制超时与失败重试策略

### 5.4 安全存储层

核心任务：

1. API Key 独立于普通业务数据保存
2. 配置编辑时支持回填非敏感字段
3. 日志脱敏

### 5.5 播放层

核心任务：

1. 音频加载
2. 播放 / 暂停控制
3. 连续播放队列控制
4. 播放进度同步
5. 最近播放页回写

## 6. 开发阶段拆分

### 6.1 P0 基础设施

目标：把数据、文件、配置、路由骨架搭起来。

任务：

1. 建立页面路由结构
2. 建立数据库与表结构
3. 建立文件存储目录规范
4. 建立模型调用抽象层
5. 建立设置数据结构和默认值
6. 接入安全存储

交付标准：

1. 可以初始化本地数据
2. 可以保存基础配置
3. 可以为后续页面开发提供数据接口

### 6.2 P1 MVP 闭环

目标：打通“导入 -> 生成文本 -> 编辑 -> 生成语音 -> 播放”。

任务：

1. 绘本列表页
2. 新建绘本页
3. 图片多选导入
4. 页面排序
5. 页面详情页三段文本编辑
6. 单页生成文本
7. 单页生成语音
8. 单页试听
9. 绘本详情页整本逐页生成
10. 连续播放

交付标准：

1. 用户可创建至少一本完整绘本
2. 每页可独立生成文本与音频
3. 整本可逐页生成并连续播放
4. App 重启后数据仍可恢复

### 6.3 P2 稳定性与体验

目标：补齐状态、错误、覆盖规则和清理逻辑。

任务：

1. 页面状态展示优化
2. 失败重试
3. 覆盖确认弹窗
4. 无音频页停止并提示
5. 删除绘本清理文件
6. 最近播放页恢复
7. 配置页可用性补全

交付标准：

1. 失败不会影响其他页面
2. 覆盖规则符合文档约束
3. 删除数据不会遗留明显垃圾文件

### 6.4 P3 可后置增强

任务：

1. 拍照导入
2. 图片旋转 / 裁剪
3. 绘本级模型覆盖
4. 多配置模板管理
5. 高级参数配置
6. 页间停顿设置
7. 替换页面图片

## 9. 待确认事项

当前文档里仍有几个需要尽快拍板的点：

1. 拍照导入是否进入 V1
2. 单页循环是否进入 V1
3. 绘本级模型覆盖是否进入 MVP
4. 页间停顿是首版可配，还是先固定默认值
5. TTS 输出音频格式是否固定为 `mp3`
6. 页面缩略图是否需要单独生成，还是直接使用原图

建议做法：

1. 先按 MVP 冻结范围开发
2. 所有“可选”项统一归入 P3，避免首版边界继续膨胀
